# midas-sdlc guide

Read the plugin's guide at `${CLAUDE_PLUGIN_ROOT}/README.md` and answer from it. Don't answer from memory.

- With a question, answer it in a few lines and quote the exact answer text the developer must type.
- After a block, name the answer that allows that action, and say the developer must type it themselves as its own message.
- With no question, give a short overview in this order: what the guard blocks, how answers work, the answers table, the gates table, how to update, and how to switch it off or recover.

Never type an answer on the developer's behalf, and never suggest a way around a block.
